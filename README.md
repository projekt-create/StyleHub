# StyleHub

Modern e-commerce website built with **Next.js**.

#  Technologies

##  Frontend Framework
- **Next.js** – React framework for building fast, SEO-friendly web applications.
- **React** – JavaScript library for building user interfaces.

---

##  Styling
- **Tailwind CSS** – Utility-first CSS framework for creating responsive and modern designs.

---

##  API & Data Fetching
- **Axios** – HTTP client for sending API requests.
- **TanStack Query** – Fetches, caches, and synchronizes server data.

---

##  Animation
- **GSAP** – High-performance animation library.
- **@gsap/react** – Official React integration for GSAP.
- **Lenis** – Smooth scrolling library.
- **SplitType** – Splits text into characters, words, or lines for text animations.
- **Typed.js** – Creates a typing animation effect.

---

##  UI Components
- **Swiper** – Responsive slider and carousel library.
- **React Icons** – Collection of popular icons as React components.
- **React Toastify** – Beautiful toast notification library.

---

##  Storage
- **js-cookie** – Library for creating, reading, and deleting browser cookies.

##  Installation

```bash
npm install
npm run dev
```
